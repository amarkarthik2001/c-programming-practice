# C Programming

A collection of C programming programs and practical implementations covering fundamental and intermediate concepts. This repository focuses on developing strong programming fundamentals, understanding memory management, mastering pointers, and improving problem-solving skills.

The programs are organized by topic for easy navigation and reference.

## Topics Covered

### 1. String Programming
- String palindrome checking
- Removing duplicate characters
- Implementing custom string functions (`strcpy`, `strlen`, `strcmp`)
- Finding the first non-repeating character
- Checking whether two strings are anagrams

### 2. Pointers, Arrays and Bitwise Operations
- Swapping two integers without a temporary variable
- Checking even or odd numbers using bitwise operators
- Checking whether a number is a power of 2
- Counting set bits
- Reversing an array using pointers
- Implementing custom `memcpy()`
- Multi-file programming

### 3. Structures
- Student information using structures
- Employee details and salary comparison
- Rectangle area and perimeter calculations
- Complex number operations using structures

## Technologies and Tools

- **Programming Language:** C
- **IDE:** Visual Studio Code
- **Compiler:** GCC
- **Version Control:** Git
- **Repository Hosting:** GitHub

## Compilation and Execution

Compile a C program using GCC:

```bash
gcc program.c -o program
```

Execute on Linux:

```bash
./program
```

Execute on Windows:

```bash
program.exe
```

## Learning Objectives

- Develop strong C programming fundamentals.
- Understand pointers and pointer arithmetic.
- Learn memory management and manipulation.
- Gain practical knowledge of bitwise operations.
- Understand arrays, strings, structures and functions.
- Improve logical thinking and problem-solving skills.
- Build a foundation for Embedded C and Embedded Linux development.

This repository serves as a reference for C programming concepts and practical implementations, with an emphasis on writing efficient, readable, and modular code.

The knowledge gained through these programs supports further learning in Embedded Systems, Embedded Software Development, and Linux Device Driver Development.
